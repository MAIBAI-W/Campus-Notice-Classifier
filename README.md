# 校园通知智能分类工具（school-radar）

一个**校园通知智能分类工具**：抓取浙江财经大学东方学院官网 + 11 个二级学院 + 11 个职能部门
子站的公开通知公告，按"跟你这个学生有没有关系"排序，压成一屏能看完的清单。

它解决的事很具体：学校网站通知太多太杂，逐条翻完一遍的时间成本远高于收益。这个工具每次
替你翻 22 个站，按 12 条成长路径（就业创业 / 考公考研 / 补考选课 / 评奖评优公示 / 公示名单 /
场地与采购 …）归类，并告诉你每条为什么被排在你面前。

- **双击即可运行**，不需要会编程、不需要装数据库、不需要浏览器插件
- 分类靠**可解释的规则**（概念词组 + 拦截词表），不是黑盒模型；机器只给建议，改不改由你点
- **所有数据只在你自己电脑上**，程序不向任何外部服务发送任何东西
- 只读公开页面；碰到需要统一身份认证或验证码的内容一律跳过

**不想配环境就直接用打包好的**：从 [Releases 页面](https://github.com/MAIBAI-W/Campus-Notice-Classifier/releases/latest)
下载 `school-radar-win64.zip`（约 21 MB），解压后双击 `school-radar\school-radar.exe`。

> 想改代码、加站点、调分类规则：先看 [`.github/prompt.md`](.github/prompt.md)（动手前必读摘要
> + 完整拦截词表），深入契约见 [`AGENTS.md`](AGENTS.md)。下面这份只讲怎么用。

## 一、怎么打开

### 情况 A：拿到的是文件夹

双击 **`start.bat`**。

第一次运行它会：找一个能用的 Python → 缺依赖自己装 → 问你 4 个问题建档案 → 抓取
（约 1–2 分钟）→ 自动打开浏览器。

提示没装 Python 时：去 <https://www.python.org/downloads/windows/> 下载安装，
**安装第一屏务必勾选 "Add python.exe to PATH"**。

想先自检环境（换电脑、抓不动时第一步就做这个）：

```bash
python app.py --doctor
```

它会逐项检查 Python 版本、依赖、控制台编码、数据目录能不能写、端口，并逐个探测 22 个站点
通不通、要不要登录，不通过的直接给修复命令。

### 情况 B：拿到的是 exe（推荐给不碰命令行的同学）

解压后双击 **`school-radar.exe`**，流程同上。它没有黑色命令行窗口，全部输出写到日志里。

- 数据存在 exe 旁边的 `data\` 里；那个位置不可写时（比如装进 `Program Files`）会自动改存到
  `C:\Users\你的用户名\AppData\Local\school-radar`
- 出问题时（比如"双击没反应"）改双击 **`school-radar-cli.exe`**：它有命令行窗口，能直接看到
  报错，也能跑 `school-radar-cli.exe --doctor` 做环境自检
- 第一次启动 Windows **SmartScreen** 会拦一下（因为程序没有花钱做代码签名），点
  「更多信息」→「仍要运行」即可；部分杀毒软件对未签名的打包程序也会误报，可以先拿
  `school-radar.exe` 去 <https://www.virustotal.com> 扫一下确认没问题
- 要反馈问题，把 `data\school-radar.log` 发出去即可，里面是启动与抓取的完整输出

### 想自己敲命令

```bash
cd 项目目录
python app.py                # 抓取 + 打开工作台
python app.py --serve-only   # 不抓取，直接看上次结果
python app.py --quick        # 只读列表标题，最快，但正文里的线索会退化
```

工作台地址是 <http://127.0.0.1:8765>（端口被占会自动往后找，终端会打印实际地址）。

## 二、第一次的 4 个问题

| 问题 | 影响什么 |
|---|---|
| **学院** | 你所在学院发的通知排前面。只能从列表里选，不用手打（避免院名写错） |
| **年级（入学年份）** | 推出你是几届、是不是毕业班；毕业班优先看到就业、双选会、答辩类 |
| **身份** | 本科生 / 专升本 / 教师辅导员 / 校友，决定受众匹配方式 |
| **专业** | 通知里点名你专业的，加一点权重 |

另外单独有一块 **「我是学校认定的资助对象」**：选"是"会让奖助学金、勤工助学、困难补助这类
通知明显靠前，选"不是"则适度靠后。单独放一块，是因为它只影响这一类，不该混进别的问题里。

随时能改：页面右上「设置」，或 `python app.py --setup`。

## 三、界面怎么用

**顶部两栏切换**

- **我的视角**（默认）：按个人相关度排序，带筛选，每条会写"为什么排在这"。
- **全部数据**：不做个性化、不带任何筛选，纯按客观权重排。想知道"学校到底发了些什么"时用。

**左侧两条轨道**

- **成长路径**：12 个类目 —— 就业创业、考公考研、教师招聘、补考选课、场地与采购、竞赛讲座、
  评奖评优公示、公示名单、教学运行、教研成果、后勤服务、其他信息。
- **学院 / 部门**：按来源筛。

两条轨道**联动**：选中某个类目后，各学院在这个类目下有多少条会跟着变；数字为 0 的灰掉，
点不动，轨道内容也不会乱跳。

**每张卡片**

- 左边大数字 = 相关度（"全部数据"视图下是客观权重），下面细条是相对最高分的占比
- 标题（**点一下直接打开学校原页面**）、一行摘要
- 标签：类目、文体（通知 / 公告 / 公示…）、来源、日期、受众人群、附件
- **虚线标签** = 这条凭哪些规则词进了这一类，鼠标放上去能看到具体命中的词。
  觉得分错了先看它，基本就能定位问题出在哪条规则
- **「疑似 ×× · 采纳」** = 模型觉得可能归错类时给的建议。**只有你点采纳它才会改**；
  而且改过一次，以后同类通知都会跟着变准

**其他**

- 搜索框按 `/` 直接聚焦；`Esc` 关弹窗
- 「重新抓取」在页面里显示进度，抓完自动刷新；页面每 5 分钟也会自动刷一次
- 默认显示近 7 天，右上角时间下拉可放宽

## 四、数据存在哪、隐私边界

| 位置 | 内容 |
|---|---|
| `data\radar.db` | 抓到的通知（标题、日期、链接、正文片段、分类结果）、抓取历史、你点过的"采纳" |
| `data\profile.json` | 你的档案（学院 / 年级 / 身份 / 专业 / 是否资助对象） |

- 服务**只监听 `127.0.0.1`**，同一局域网里别人打不开你的页面。
- 不上传、不调任何第三方服务；抓的是学校官网本来就公开列出的通知。
- 不碰登录态：撞统一身份认证、验证码一律跳过，界面上会如实标注"本轮哪些来源异常"。
- 想彻底清空：删掉整个 `data\` 文件夹，下次运行重新建库。
- **发给别人之前**：先删掉 `data\`，否则等于把你的档案和已读记录一起发出去了。

## 五、怎么退出程序

**关掉浏览器标签页不算退出。** 这个工具是"本机上的一个小服务 + 一个网页"，你关掉的只是网页，
服务还在后台跑，并且会占着它自己目录里的文件（于是你删不掉、也换不了新版本）。

正确的退出方式：

1. 回到那个网页，点右上角红色的 **「退出」** 按钮 → 确认 → 服务停止，这个标签页就可以关了。
   正在抓取时退出会中断本轮，下次打开再抓即可。
2. 如果页面已经打不开、又想把后台进程清掉，用命令行版看一眼：

   ```bash
   taskkill /IM school-radar.exe /F
   ```

3. 用 `start.bat`（源码版）跑的，直接在那个黑色窗口按 `Ctrl+C`。

> 另外：**重复双击不会开出第二个程序**。第二个实例发现后台已经有了，会直接把浏览器
> 叫到已经在跑的那个页面上，然后自己退出。

## 六、常见问题

**打开是空白页 / 一直"正在载入"**
服务没在跑。回命令行窗口看有没有报错，重新双击 `start.bat`。

**列表是空的**
第一次还没抓完，或近 7 天确实没有符合筛选条件的通知。点「重新抓取」，或放宽时间范围。

**某个学院的通知一条都没有**
两种正常情况：① 该站只在校内网可达（页脚会列出是哪几个）；② 该站列表页需要统一身份认证。
这两种都不该用输密码的方式绕过去。

**开着 Clash / 代理时抓不动**
抓取默认不走系统代理。仍异常就先跑 `python app.py --doctor`，它会逐站告诉你通不通。

**端口 8765 打不开**
终端启动时会打印实际地址（被占用会自动换）。也可以指定：`python app.py --port 8899`。

**分类明显不对**
先看卡片上的虚线标签（写了凭什么这么分），再点「疑似…采纳」，或者把具体哪一条反馈出来。
工具的规则表就是靠真实反例一条条改准的。

**想加/去掉某个来源、调抓取深度**
不用改代码：在项目目录放一个 `config.local.json`，可以关站点、加站点、调权重和抓取限额。
格式见 `AGENTS.md` §5。
